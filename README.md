# IU-DLBCSWAD01 Task 3

This repository contains the solution for Task 3 of the DLBCSWAD01 course. The project is a static HTML website for a sample online bookstore.

## Cloning the Repository

To clone this repository, run the following commands in your terminal:

```bash
git clone https://github.com/Nonnyjoe/IU-DLBCSWAD01-TASK-3.git
cd IU-DLBCSWAD01-TASK-3
```

## Using the Code Base

This project is entirely static, so you can simply open the `index.html` file in your favorite web browser to view the website.

Double-click `index.html` from your file explorer, or run:

```bash
open index.html
```

## Summary

- **Static HTML Website:** A simple website built with HTML and CSS.
- **No Dynamic Content:** Since this is a static project, there is no server-side or dynamic client-side behavior.
- **Easy Setup:** Clone the repository and open `index.html` to view the website.
